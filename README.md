# 🚀 NorthPeak Digital – Premium SaaS Landing Page

A modern, fully responsive, premium digital agency landing page built using **HTML5**, **CSS3**, and **Vanilla JavaScript**.

The project showcases a clean SaaS-inspired design with glassmorphism, smooth animations, responsive layouts, interactive UI components, and optimized performance.

---

## 📌 Project Overview

NorthPeak Digital is a fictional digital agency website designed to demonstrate modern front-end development practices.

The landing page focuses on:

- Professional UI/UX
- Responsive Design
- Performance
- Accessibility
- Interactive User Experience
